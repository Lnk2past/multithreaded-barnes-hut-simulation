# multithreaded-barnes-hut-simulation

This is my attempt at a multithreaded implementation of the Barnes-Hut approximation for the n-body problem. Very specifically I want this to be as pure of a C++ implementation as I can, with all of the visualization handled by [Holoviews](https://holoviews.org/) + [Panel](https://panel.holoviz.org/). I want realtime visualization and full control over configuring the simulation.

More details to come.

## Motivatiom

This was originally my submission for the Anaconda Data App Contest back in 2023. I have since learned so much more in various areas and want to see how far I can take this.
