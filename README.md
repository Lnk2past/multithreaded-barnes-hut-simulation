# multithreaded-barnes-hut-simulation

This is my attempt at a multithreaded implementation of the Barnes-Hut approximation for the n-body problem. Very specifically I want this to be as pure of a C++ implementation as I can, with all of the visualization handled by [Holoviews](https://holoviews.org/) + [Panel](https://panel.holoviz.org/). I want real-time visualization and full control over configuring the simulation.

More details to come.

## Motivation

This was originally my submission for the Anaconda Data App Contest back in 2023. I have since learned so much more in various areas and want to see how far I can take this.

## AI Disclaimer

The original implementation written in 2023 was purely written by me (with the usual suspects of Stack Overflow, Discourses, etc. helping along the way). In reviving this code I have used AI to assist in identifying bottlenecks and debugging faulty code. This will always be the extent of AI use in this project.
